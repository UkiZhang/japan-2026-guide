# Japan 2026 PWA

Upload **all files and the `icons` folder** to the root of your GitHub repository.

GitHub Pages settings: **Deploy from a branch → main → /(root)**.

After deployment, open the site once in Safari, then Share → Add to Home Screen.

When a new day is ready, replace `day2.html`, `day3.html`, etc., and change `CACHE_NAME` in `service-worker.js` (for example v3 → v4) so installed devices refresh the offline cache.
